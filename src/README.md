## Instruções de Utilização

### Instalação
O site em HTML/CSS/JS é um projeto estático, logo pode ser utilizado tanto em servidores web quanto diretamente abrindo o arquivo `index.html` em um navegador.

Para configurar localmente:
1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/ICEI-PUC-Minas-PMV-SI/pmv-si-2025-2-pe1-t1-pmv-si-2025-2-pe1-projmeunegociofacil.git
    ```
2.  **Navegue até o diretório do projeto:**
    ```bash
    cd pmv-si-2025-2-pe1-t1-pmv-si-2025-2-pe1-projmeunegociofacil
    ```
3.  **Abra o arquivo `index.html` no seu navegador preferido.**

### Como Usar
Após a instalação, basta abrir o arquivo `index.html` no seu navegador. A navegação entre as seções do site é feita através do menu principal, após o login.
